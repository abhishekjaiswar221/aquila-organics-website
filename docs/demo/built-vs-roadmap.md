# Built now vs. what comes next

Content for one slide (or a one-page handout). Plain language, no promises beyond what exists.

## Built and working today

| Area | What is there |
|---|---|
| Public website | Home, Fragrances and Flavours (with all application pages), About, Innovation, Sustainability, Compliance, Careers, Contact, Privacy |
| Product catalogue | Database-backed, searchable by name, code or CAS number (with or without hyphens), product pages with search-engine data |
| Requests for quotation | Multi-product RFQ with quantities, units and file attachments, reference numbers, spam protection, confirmation page |
| Enquiry handling | Admin inbox with status tracking and secure attachment downloads |
| Product management | Create, edit, categorise, attach datasheets and safety documents, review imported drafts. **Nothing is published until a super admin verifies it** |
| Careers | Job openings managed in the admin, public application form with CV upload, HR inbox with audited CV download and deletion |
| Users and roles | Five roles (super admin, administrator, sales manager, content editor, HR manager) with strict permissions, one-time passwords, forced first-login change, disable and reset |
| Accountability | Audit log of every admin change, free of personal data |
| Search and speed foundations | Sitemap, structured data, redirects from the old site, responsive layouts, accessibility checks on every page |
| Quality | Automated tests across the site, the admin and the browser at four screen widths |

## Needs the client before launch

| What | Why it matters |
|---|---|
| Verified product list with CAS numbers | The imported legacy products are drafts only; we never publish unverified chemistry |
| Company facts to confirm | Head office location, founding year, certificates and expiry dates, EcoVadis rating |
| Approvals | Wording for Oud/Bakhoor, the shisha line and toll manufacturing; consent to name people |
| Photography | The site currently uses neutral placeholders |
| Notification contacts | Who receives each type of enquiry; the correct flavours mailbox address |
| Legal review | The privacy notice, which now also covers job applicants; a retention period for applicant data |
| Accounts | Domain, hosting, production database, email provider, file storage |
